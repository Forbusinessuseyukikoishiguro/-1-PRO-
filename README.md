## 特長

- **MECEのホーム**：まなぶ → つたえる → すすめる の3段構成
- **海辺の学校メニュー**：どの教室からでも他教室・ホームへ回遊
- **APIキーは一度設定すれば継続**：全教室で共有。端末のブラウザ内のみに保存、送信先はAnthropic APIだけ。Claude.ai内ではキー不要
- **保存：Excel / Word / CSV / PDF / Markdown / PPT / PNG**。自動保存がブロックされる環境でも、**保存パネル**（ユーザー操作）で保存可。PDFは印刷→「PDFとして保存」（日本語OK）
- **エラーログ**：エラー時だけ「🐞ログ」が出現。`onerror`／未処理Promise／`console.error`を捕捉、コピー・クリア可
- **遊び心（控えめ）**：学習うさぎ、各教室の小うさぎ（タップで短い応援）、蟹・カモメ・貝、季節でヒトデの色とアクセントが変化。すべて低透明度・低速・`prefers-reduced-motion`対応

## アーキテクチャ（技術メモ）

- 各教室を **base64で内包**し、開くと **ページ自体が切り替わる**方式（`document.write`）。**iframeは不使用**（サンドボックスでブロックされにくくするため）。
- ハブは開いた教室へ、共通の足回りを**注入**します：海辺メニュー（`location.hash` + reload で回遊）／APIブートストラップ（`fetch`にキーを自動付与）／エラーログ／うさぎ。
- 保存は `<a download>` のクリックを横取りし、**ユーザー操作の保存パネル**へ置換する共通モジュールで実現（SheetJS／PptxGenJS／Word／CSV／Markdown／SVG をまとめて捕捉）。`URL.revokeObjectURL` を遅延させ、後からの保存でもBlobが生きるようにしています。
- ランタイムAPI：`window.__USAUSA_SUITE__ = { version, edition:'PRO', build:'2026-06-12', tools, openTool, decodeTool, buildToolDoc, apiTest, kGet, kSet, apiBootstrap, logAdd }`

### 設計ルール（このスイートの約束）

- シングルHTML・外部依存ゼロ・オフライン対応は絶対条件
- 本物のOOXML出力（Word/PPT/Excel）。HTMLエクスポートでの代用はしない
- 事実と所感を分離。捏造統計・架空の引用は禁止（ウソなく）
- 公開用には固有名を出さない（役職名で代替）

## 開発・ビルド・テスト

ビルドはPythonで単体HTMLを生成し、jsdomの商用テストで**ゼロバグ**を確認してからバージョンを上げます。

```bash
# ビルド（5教室を base64 内包して単体HTMLを生成）
python3 build_zen_suite_v11.py
# 出力: usausa-zen-suite-PRO-v1_8_1-20260612.html

# 商用グレード・テスト（jsdom / 166項目）
NODE_PATH=$(npm root) node test_suite.js
```

テスト区分：ホワイトボックス（静的構文）／単体（base64往復）／API連携／MECE・保存・PDF・キー継続／ブラックボックス（画面の契約）／海辺メニュー／エラーログ／うさぎ・季節・タップ応援／結合＆システム（クリック→ページ書換→正しい教室）／モンキー（乱打・異常系）／API接続。

- 失敗時は「ツールのバグ」か「テストコードの誤り」かを切り分けて修正します。
- ゼロバグ確認後にのみ、バージョンを **5箇所**（ファイル先頭コメント／タイトル／バッジ／フッター／ランタイム）で統一更新します。

> ビルド／テストのスクリプト（`build_zen_suite_v11.py`・`test_suite.js`・各注入モジュール）が必要なら、リポジトリへ書き出せます。
